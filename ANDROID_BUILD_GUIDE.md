# 📱 Сборка APK для Android через GitHub Actions

В проект уже добавлен и настроен **Capacitor (Android)** и готовый рабочий процесс **GitHub Actions** (`.github/workflows/build-apk.yml`), который автоматически компилирует `.apk` файл при каждом пуше или нажатии кнопки в GitHub.

---

## 🚀 Способ 1: Автоматическая сборка в GitHub (самый простой)

Вам не нужно устанавливать Android Studio или SDK на свой компьютер! Всё соберётся на серверах GitHub.

### Шаг 1: Экспорт или пуш в GitHub
1. В верхнем правом меню AI Studio нажмите **Export** → **Export to GitHub** (или запушьте код в свой репозиторий на GitHub).
2. Откройте ваш репозиторий на сайте [github.com](https://github.com).

### Шаг 2: Запуск сборки
GitHub Actions запустится автоматически при пуше! Либо вы можете запустить его вручную:
1. Перейдите во вкладку **Actions** в вашем репозитории на GitHub.
2. В левой колонке выберите воркфлоу **«Build Android APK»**.
3. Нажмите кнопку справа **«Run workflow»** → выберите ветку `main` → **«Run workflow»**.

### Шаг 3: Скачивание APK на телефон
1. Подождите около 2-3 минут, пока сборка завершится (появится зелёная галочка ✅).
2. Кликните по завершённому запуску (например, *«Build & Package Android APK»*).
3. Внизу страницы в блоке **Artifacts** найдите файл **`SheepVsWolves-Android-APK`** и нажмите на него для скачивания (скачается zip-архив с файлом `SheepVsWolves-debug.apk`).
4. Распакуйте и отправьте файл `SheepVsWolves-debug.apk` на ваш телефон (через Telegram, Google Диск, кабель или браузер).
5. Нажмите на файл на телефоне и подтвердите установку («Разрешить установку из этого источника»).
6. Готово! Игра установлена как нативное приложение Android.

---

## 💻 Способ 2: Локальная сборка на компьютере (через Android Studio)

Если вы клонировали репозиторий на свой компьютер:

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Соберите веб-версию и синхронизируйте проект с Android:
   ```bash
   npm run cap:build
   ```
3. Откройте проект в Android Studio:
   ```bash
   npx cap open android
   ```
4. В Android Studio нажмите **Build** → **Build Bundle(s) / APK(s)** → **Build APK(s)**.
5. Готовый APK файл будет в папке:
   `android/app/build/outputs/apk/debug/app-debug.apk`
